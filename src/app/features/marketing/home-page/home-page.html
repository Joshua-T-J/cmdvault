Straight talk about security

A secret gist is unlisted, not private. Anyone with its link can read it. Here’s how CmdVault keeps that from hurting you.

  • Token in memory

    Your token stays in this tab’s memory unless you choose otherwise. Never in localStorage.

  • Secrets caught before saving

    Keys, tokens and passwords are flagged, and you can swap them for a placeholder.

  • Encryption, coming soon

    A passphrase-derived AES-GCM key, all in your browser with Web Crypto.

  • Strict content security policy

    No third-party scripts, and requests only go to GitHub’s API.
