The short version

  • Your commands are saved in one secret gist on your own GitHub account.
  • Your browser talks to GitHub directly. Nothing passes through a GistVault server — there isn’t one.
  • Your token stays in this tab’s memory unless you choose to remember it for the tab.
  • No accounts, no cookies, no analytics or trackers inside the app.
  • You can export everything, delete the gist, or revoke the token at any time.

What GistVault handles

GistVault runs entirely in your browser. While you use it, it works with:

  • Your commands — titles, command text, tags, shell, notes, whether each one is a favorite and how often you copied it.
  • Your GitHub token — used only to call api.github.com on your behalf.
  • Your public GitHub profile — your username, display name and avatar, shown in the account menu.
  • A few local settings — the ID of your vault gist, a random device ID used when merging edits, and your theme choice.

Values you type into placeholders (for example a host name or pod name) are used once to build the copied command and are never saved.

Where it is stored

What GistVault stores, where, and for how long
Data Where How long
Commands Secret gist on your GitHub account (gistvault.json) Until you delete them or the gist. GitHub keeps gist revision history.
GitHub token This tab’s memory; optionally the tab’s session storage Until you reload, sign out, or close the tab
Vault gist ID, device ID Your browser’s local storage Until you clear site data
Theme choice Your browser’s local storage (only if you pick Light or Dark) Until you change it or clear site data
Placeholder values Nowhere — memory only while the dialog is open Discarded when you copy or cancel

Your token is never written to local storage, which survives browser restarts and is readable by any script on the page.

Who can see your vault

A secret gist is unlisted, not private. It doesn’t appear in search or on your profile, but anyone who has its URL can read it. GistVault never shows that URL in its interface.

  • You — through GistVault or directly on gist.github.com.
  • GitHub — which hosts the gist under its own privacy statement.
  • Anyone with the link — if you share it, or it leaks.

That is why GistVault checks for passwords, API keys and tokens before every save. Keep secrets out of your vault — use a placeholder such as {{ '{{' }}API_KEY{{ '}}' }} instead. See the security model for details.

What we don’t collect

  • No GistVault accounts, emails or passwords.
  • No cookies.
  • No analytics, tracking pixels or session recording inside the app.
  • No third-party scripts, ads or CDNs — fonts are served from our own domain.
  • No copies of your commands, token or profile on any server we run.

GitHub and hosting

GitHub

Your browser sends requests straight to api.github.com to read and save your vault. GitHub processes that data under the GitHub General Privacy Statement.

Hosting

The app’s files are served as static pages by our hosting provider (Vercel). Like any web host, it may log standard request details such as IP address, browser and time of request to operate and secure the service. Those logs never contain your commands or token, because they are sent to GitHub, not to us.

Your controls

  • Export — use Export JSON in the vault to download every command.
  • Sign out — clears the token and the vault from this tab.
  • Revoke the token — on GitHub under fine-grained tokens or classic tokens.
  • Delete your data — delete the gist described as “GistVault data” on gist.github.com.
  • Clear local settings — clear this site’s data in your browser settings.
